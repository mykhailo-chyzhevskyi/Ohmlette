# Локальний backend — лабораторна №2

Потрібен Python 3.11+; GPU й хмарний API не потрібні. Backend призначений для власного ПК в довіреній локальній мережі, не для публічного сервера. PDF і текст не передаються AI-провайдеру. За посиланням сервер звертається до сайта виробника.

## Запуск на Windows

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe server.py --host 0.0.0.0 --port 8000
```

Команди виконуються в цій папці. Для macOS/Linux: `python3`, `.venv/bin/python`. Доступ із телефона потребує однієї Wi-Fi мережі та дозволу на порт 8000 у приватному профілі firewall. Не відкривайте порт у роутері.

В Android: «Даташити» → адреса `http://IP-КОМП’ЮТЕРА:8000` → артикул → посилання або файл → «Створити картку». Для емулятора адреса `http://10.0.2.2:8000`. HTTP дозволено тільки в debug-збірці.

## Контрольний приклад

- PDF: https://www.onsemi.com/pdf/datasheet/bzx84c2v4lt1-d.pdf
- Артикул: BZX84C2V4LT1G.
- Очікування: AI-тип «Діод», статус «неперевірено», фрагменти з артикулом і номерами сторінок. Пошук артикулу є пошуком фрагментів, а не гарантованим вибором рядка таблиці.
- Якщо сайт блокує завантаження сервером, збережіть PDF і виберіть файл у застосунку.

## API

- `GET /health` — перевірка сервера.
- `POST /v1/cards` — JSON: `partNumber` та рівно одне з `url` / `pdfBase64`.
- `GET /documents/{sha256}.pdf` — оригінал для перегляду доказів.

Обмеження MVP: текстовий PDF до 15 МіБ і 100 сторінок. Локальне сховище PDF — `storage/`; для видалення документа видаліть відповідний файл при зупиненому сервері. Сервер не має авторизації, ізоляції PDF-парсера та обмеження паралельних задач: не публікувати в інтернеті, використовувати тільки власні документи й локальну мережу.

## Що тут AI

`classifier.py` — supervised multinomial Naive Bayes, навчений на невеликому відкритому в коді наборі текстових прикладів чотирьох типів компонентів. Він класифікує першу сторінку. Це справжній простий ML-компонент, але не LLM і не універсальний аналізатор даташитів. Правила пошуку артикулу й витягування PDF-тексту не називаються AI.

Перша лабораторна реалізація повертає тип та докази, **не заповнює min/typ/max**. Повноцінні параметри, український переказ і локальна мовна модель на Pixel 8 — наступні етапи. Кнопка збереження записує JSON-картку у внутрішні файли Android; список збережених карток та офлайн-копія PDF ще не реалізовані.

Тести: `.\.venv\Scripts\python.exe -m unittest -v`.
