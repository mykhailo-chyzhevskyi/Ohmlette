# Групи розрахунків

Папки нижче задають межі майбутніх модулів. Формули поки залишаються в прототипі; перенесення та підключення Gradle виконується окремим етапом.

- `components/`: номінали, резисторні мережі, допуски, конденсатори, маркування.
- `signals/`: фільтри, RLC, RMS, PWM, часові й частотні перерахунки.
- `sensors/`: NTC, інтерполяція готових таблиць, шунти.
- `rf/`: dB/dBm, атенюатори, КСХН, радіолінії, антени, LoRa.
- `pcb/`: AWG, провідники, доріжки, microstrip.

Кожна група залежить від core, а не від іншої групи, UI, бази чи AI. Спільна математика переноситься у core; координація кількох розрахунків — у сценарій верхнього рівня. Для жорсткого контролю ці межі оформлюються окремими Gradle-модулями при перенесенні коду: папка сама по собі не забороняє імпорти.
