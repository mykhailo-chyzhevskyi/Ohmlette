# Реальний AI-компонент

Джерело: [classifier.py](../../backend/classifier.py). AI виконується на ПК у backend. На телефоні зараз немає моделі inference, завантаження ваг або використання NPU.

## Алгоритм і навчання

Це власна коротка реалізація **multinomial Naive Bayes**, а не нейронна мережа чи перенавчена відкрита LLM. Зовнішньої ML-бібліотеки немає.

Вбудований TRAINING містить 16 коротких англомовних прикладів, по 4 на клас:

- diode — діод;
- resistor — резистор;
- capacitor — конденсатор;
- inductor — дросель.

При створенні Classifier підраховуються слова для кожного класу та спільний словник. Токенізація залишає лише англійські слова `[a-z]{2,}`. Для оцінки використовуються частоти зі згладжуванням +1 і сума логарифмів імовірностей. Окремого файла навчених ваг немає.

Backend передає перші 12000 символів тексту **тільки першої сторінки**, а не весь PDF. Невідомі словнику слова ігноруються. Якщо відомих слів немає — результат unknown / «Не визначено». Інакше завжди вибирається найкращий із чотирьох класів. Порога впевненості немає.

## Вихід

Приклад форми відповіді:

```json
{
  "type": "diode",
  "label": "Діод",
  "method": "multinomial-naive-bayes-v1",
  "unverified": true
}
```

Числовий confidence не повертається. Label — фіксований український переклад назви категорії.

## Що робиться без AI

- pypdf витягує оригінальний текст.
- server.py знаходить артикул нормалізованим текстовим пошуком.
- Номер сторінки визначається під час обходу PDF.
- summary і limitations — фіксовані рядки.
- min/typ/max, умови вимірювання та pinout не розбираються.

AI не формує український переказ і не перевіряє електричну придатність компонента. Називати результат заповненою карткою характеристик або консультацією LLM неправильно.

## Якість і ризики

Чотири короткі тестові фрази підтверджують роботу алгоритму, але не доводять точність на реальних даташитах. Документ непідтримуваного класу може бути помилково віднесений до одного з чотирьох класів. Навчальний набір малий; цифри, графіки, таблиці й корпуси класифікатор не аналізує.

Перевірений приклад №2 — даташит onsemi BZX84C2V4LT1G: клас diode. Не поширювати цей одиничний успіх на всі PDF.

План локальної відкритої мовної моделі, шаблонів і менеджера завантажень описаний в [DATASHEET_AI.md](../DATASHEET_AI.md). Це майбутній напрям, не поточний стан.
