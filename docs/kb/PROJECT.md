# Призначення та стан

Ohmlette — Android-інструменти електронного інженера. Основна платформа — телефон, контрольний пристрій для подальших локальних моделей — звичайний Pixel 8. Майбутня версія для ПК ще не реалізована.

## Що працює в коді

| Частина | Поточні можливості |
| --- | --- |
| Одиниці | Перерахунок префіксів від піко до гіга в межах однієї вибраної величини |
| Номінали | Три найближчі номінали E12/E24/E96 та їх відхилення від цілі |
| Даташити | URL або локальний PDF + артикул → HTTP → Python backend → тип компонента та текстові докази |
| Стан запиту | Завантаження, картка або повідомлення про помилку |
| Збереження | JSON поточної картки у внутрішні файли Android; адреса backend у SharedPreferences |

Перерахунок одиниць не є парсером арифметичних виразів. Відхилення стандартного номіналу не є допуском фізичного резистора.

## Перевірений сценарій №2

На емуляторі Medium Phone API 37.0 виконано URL-запит до даташита onsemi для BZX84C2V4LT1G. Відображено тип «Діод» і фрагмент зі сторінки 3. Перевірено помилку недоступного порту 8001 та повторний успішний запит після повернення 8000. Для зв'язку використано adb reverse.

Скріншоти та звіт лежать у батьківській робочій папці: `../../../lab2_report/` відносно цього файла. Сценарій вибору локального файла і відкриття PDF реалізований, але окреме ручне підтвердження цих дій поки не зафіксовано.

## Що ще не реалізовано

- Повне розділення на core, calculations, features і окремі ViewModel.
- Арифметичний калькулятор, резисторні мережі, автопідбір до шести резисторів, допуски, RC-фільтри та решта функціонального чекліста.
- Локальна LLM на телефоні, менеджер завантажуваних моделей, OCR і чат до PDF.
- Структуровані параметри min/typ/max та їх умови: `parameters` у відповіді зараз порожній.
- Бібліотека збережених карток, повноцінна історія та офлайн-копія PDF на телефоні.

## Рішення, які слід зберігати

AI-функція продукту в перспективі має бути локальною. Backend на власному ПК використовується зараз для вимоги лабораторної №2 про HTTP; він не звертається до хмарного AI, але отримує PDF з телефона. При URL-вводі він завантажує документ із зовнішнього сайта.

Перші майбутні шаблони: діод, резистор, конденсатор, дросель. Точний артикул задає користувач. Наявність чернетки не підтверджує правильність її типу чи чисел.
