# Knowledge Base Ohmlette

Початкова база знань для лабораторної №3. Перевірено за кодом 17.11.2026. Вона описує поточний MVP; після змін коду відповідні розділи потрібно оновлювати.

Порядок читання:

1. [PROJECT.md](PROJECT.md) — призначення, стан і межі продукту.
2. [ARCHITECTURE.md](ARCHITECTURE.md) — фактичні файли та потік даних.
3. [API.md](API.md) — HTTP-контракт.
4. [AI.md](AI.md) — реальний AI-компонент.
5. [TESTING.md](TESTING.md) — запуск і перевірки.

Джерело істини щодо поведінки — код, щодо вимог — завдання й погоджені рішення користувача. При розбіжності KB з кодом її потрібно зафіксувати, а не дописувати вигадану реалізацію.

Не плутати цю базу з [цільовою архітектурою](../../ARCHITECTURE.md) та [планом AI-даташитів](../DATASHEET_AI.md). Вони описують також майбутні функції.

У межах цього першого таску створено лише KB. AGENTS.md, експеримент «без контексту / з контекстом» і нова функція лабораторної №3 ще не виконані.
