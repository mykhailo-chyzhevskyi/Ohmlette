# Лабораторна №2 — поточний MVP

## Сценарій

Android → URL або PDF-файл + артикул → HTTP POST /v1/cards → backend → валідація, PDF-текст, локальний ML-класифікатор → чернетка картки з доказами → Android.

Перший інструмент — картка даташита. GPU й хмарний API не потрібні. Обчислення виконуються на власному ПК/ноутбуці для вимоги курсу про backend. Остаточний локальний AI на телефоні залишається окремим етапом.

## Відповідність завданню

| Вимога | Реалізація |
| --- | --- |
| Функціональний екран | Даташити в Android, URL/файл/артикул, результат |
| Введення/вибір даних | URL або системний вибір PDF |
| HTTP API | POST /v1/cards, JSON |
| Перевірка даних | Розмір, тип PDF, артикул, текстовий шар, межа сторінок |
| AI основного сценарію | Навчений multinomial Naive Bayes визначає категорію компонента |
| Результат/завантаження/помилка | Картка, індикатор запиту, помилки backend/мережі |

## Межі MVP

AI тут — простий класифікатор, не мовна модель. Параметри min/typ/max ще не нормалізуються; картка містить текстові докази. Не обіцяємо визначення конкретного рядка таблиці за частковим артикулом. Збереження картки є записом JSON; бібліотека карток і офлайн-PDF ще попереду.

Це перша вертикальна реалізація лабораторної №2, а не завершення всього AI-напряму. Перед значним розширенням потрібно виконати описане в ARCHITECTURE.md розділення core/calculations та керування станом features.

Повторна перевірка: помилка порту 8001 зафіксована; адресу 8000 відновлено й картку отримано повторно. Попередня перешкода запуску емулятора більше не блокує цей сценарій. Вибір локального PDF і кнопка відкриття PDF ще не перевірені вручну; у звіті це не заявлено.
